# 🖤 Minimalist Developer Portfolio & Blog

## 📝 Description
A clean, minimalist personal portfolio and blog designed to showcase my software development journey, projects, and technical writings. Built with a focus on typography, whitespace, and a seamless user experience. This project demonstrates foundational web development skills and an entrepreneurial approach to personal branding.

## 🚀 Features
* **Minimalist UI/UX:** Clean, distraction-free reading experience.
* **Top Navigation Bar:** Easy access to all core pages (Home, About, Blog, Contact).
* **Fully Responsive:** Adapts perfectly to mobile, tablet, and desktop screens.
* **Dynamic Interactivity:** Smooth scrolling and UI interactions.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure and accessibility.
* **CSS3:** Custom styling, Flexbox layout, and mobile-first media queries.
* **JavaScript:** DOM manipulation and interactive elements.
